# TOWER ASSEMBLY MODULE — Requests

Drop a file here when another module needs something from TOWER ASSEMBLY MODULE (e.g. section pool access, tower height info, theme data).

## Format
Create a file named `[REQUESTING MODULE]-[short-description].md` with:
- **From:** requesting module name
- **Request:** what is needed
- **Reason:** why it is needed
- **Status:** Pending / Accepted / Rejected
