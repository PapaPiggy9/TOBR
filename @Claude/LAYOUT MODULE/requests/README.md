# LAYOUT MODULE — Requests

This folder contains inter-module requests. Other modules drop a markdown file here when they need something from LAYOUT MODULE (e.g. a new section size, a new area in the lobby).

## Format
Create a file named `[REQUESTING MODULE]-[short-description].md` with:
- **From:** requesting module name
- **Request:** what is needed
- **Reason:** why it is needed
- **Status:** Pending / Accepted / Rejected
