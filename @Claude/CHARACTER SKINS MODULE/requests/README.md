# CHARACTER SKINS MODULE — Requests

Drop a file here when another module needs something from CHARACTER SKINS MODULE (e.g. a new skin, NPC placement, pet companion behavior).

## Format
Create a file named `[REQUESTING MODULE]-[short-description].md` with:
- **From:** requesting module name
- **Request:** what is needed
- **Reason:** why it is needed
- **Status:** Pending / Accepted / Rejected
